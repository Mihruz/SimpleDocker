# Simple Docker Project

В данном проекте я работал с готовым образом nginx.
Написал простой веб-сервер работающий через FastCGI.
Проверил безопасность Docker-образов с помощью Dockle.
Запускал и останавливал многоконтейнерные приложения с помощью написанного Docker Compose.

## Задачи
### Часть 1. Готовый Docker
Скачайте официальный образ nginx.
Запустите контейнер и проверьте его работу.
Настройте маппинг портов (80 и 443) и убедитесь, что стартовая страница доступна в браузере.
### Часть 2. Операции с контейнером
Создайте и настройте файл nginx.conf для отображения статуса сервера.
Перезапустите nginx внутри контейнера и проверьте доступность страницы /status.
Экспортируйте и импортируйте контейнер.
### Часть 3. Мини веб-сервер
Напишите простой веб-сервер на языке C с использованием FastCGI.
Настройте nginx для проксирования запросов на порт 8080.
### Часть 4. Свой Docker
Создайте Dockerfile для сборки образа, который:
Собирает исходники мини-сервера.
Запускает сервер на порту 8080.
Копирует файл nginx.conf внутрь образа.
Проверьте работу образа и настройте автоматическое обновление конфигурации.
### Часть 5. Dockle
Проверьте безопасность созданного образа с помощью Dockle.
Устраните все ошибки и предупреждения.
### Часть 6. Базовый Docker Compose
Напишите файл docker-compose.yml для управления двумя контейнерами:
Первый контейнер запускает ваш сервер.
Второй контейнер с nginx проксирует запросы.
Проверьте работу проекта через браузер.
